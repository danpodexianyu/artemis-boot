# Artemis Boot
基于 SpringBoot 4.1.1 + JDK21 搭建的后端基础脚手架，分8个阶段迭代开发，内置统一返回、全局异常、参数校验、JWT鉴权、MyBatis、Flyway、接口文档等基础能力。

## 模块说明
- 统一返回封装：全局标准响应体，所有接口返回结构一致
- 全局异常处理：统一捕获并包装各类异常，屏蔽底层堆栈信息
- 参数校验：基于 Jakarta Validation 实现，支持JSON请求体、表单查询参数、路径/请求单参数校验，校验失败返回标准化错误信息，OpenAPI文档自动展示校验约束

## 使用提示
参数校验直接在DTO/入参上添加jakarta校验注解即可，无需额外异常处理；校验相关错误统一返回参数校验错误码。
